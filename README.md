# Compustar Botswana

Static React advertising site for Compustar Botswana.

The site is built with Vite, React, GSAP animations, and a product enquiry catalogue. It is designed for GitHub Pages with the custom domain:

```text
compustar.co.bw
```

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
